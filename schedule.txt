# ---- Special day schedules (Convocation, Closing Exercises...) ----
# A day marked "special" in the calendar file uses the timetable named here
# instead of the A-H rotation. It does NOT consume a cycle day.
# @special LABEL | HH:MM-HH:MM | what | grades
#   grades = ALL, or a list like 9,10,11 (same rule as @finals).
#   "first-of-day N" as the label means: whatever class the student has in the
#   FIRST period of cycle day N. Convocation gives every course a 25-minute
#   taster, one per rotation day, and the eight first periods happen to be
#   eight different letters -- so this is read off @day rather than hardcoded,
#   and it stays right if the school ever changes the rotation.
