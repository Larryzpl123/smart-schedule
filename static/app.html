Back up your schedule

In local mode your schedule is in this browser only. Nothing is on the server, so if this browser's data is cleared there is no copy anywhere and nobody can get it back. Keep one of these somewhere.
Copy is usually the better one on a phone: paste it into Notes and it is always findable. A downloaded file often is not.

Restore

Paste a backup here (or pick a .txt) to replace what is in this browser. This overwrites whatever is here now.

Your schedule lives in this browser

Local mode keeps everything here and nothing on the server. That is what makes it private — and it means there is no copy anywhere else. Clearing this browser's data, or losing this device, loses your schedule, and nobody can restore it for you.
This browser deletes stored data on a timer.
You can turn this off for good in Settings.

Keep this app where it cannot be deleted

    Do it before you type your schedule in. A Home Screen app gets its own storage, separate from this browser's, so nothing you enter here follows it across. If you have already entered one, copy it out with Backup first and paste it back in over there.
    If you only ever use this in a browser tab and do not mind the risk, turn it off. Settings can bring it back.
